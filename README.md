# Python Soccer Showdown

A fast-paced local multiplayer 2D soccer game built with `pygame`.

## Features
- 2 players on one keyboard.
- Ball physics with bounce, drag, and collision response.
- Goal detection and scoreboard.
- 3-minute match clock and end-of-game winner banner.
- Quick restart after full-time.

## Controls
- **Player 1 (Blue):** `W A S D` to move, `F` to kick.
- **Player 2 (Red):** Arrow keys to move, `Right Ctrl` (or `Right Shift`) to kick.
- `R` to restart once match ends.
- `Esc` to quit.

## Run
```bash
pip install pygame
python soccer_game.py
```
